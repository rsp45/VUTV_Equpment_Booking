# VUTV Equipment Booking — HCI Case Study

An end-to-end Human-Computer Interaction (HCI) case study researching, defining, and structuring a self-service equipment booking system for VUTV (Vijaybhoomi University Student Media).

## 📌 Project Overview
This project addresses scheduling conflicts and invisible email reservations in student media equipment management. Following strict HCI research and Information Architecture (IA) methodology, this deliverable contains research synthesis, user personas, empathy maps, user journey maps, card sort analysis, tree testing evaluations, and MoSCoW / DFV feature prioritization.

- **Course**: STET301 · Human-Computer Interaction (Mid-Term)
- **Author**: Rudra Patel
- **Live Tree Test**: [tree-test-red.vercel.app](https://tree-test-red.vercel.app/)
