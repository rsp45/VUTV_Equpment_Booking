# VUTV Equipment Booking System

An end-to-end Human-Computer Interaction (HCI) case study and interactive prototype designed for **VUTV (Vijaybhoomi University Student Media)**. This project tackles the logistical nightmare of manual equipment checkouts by researching, defining, and structuring a self-service digital booking system.

The core objective is to empower student producers to browse curated production kits, check real-time gear availability, make reservations, and avoid scheduling conflicts—all within a seamless, mobile-first interface.

## 🛠️ Tech Stack
- **HTML5 & CSS3:** Custom-built UI with a bespoke "Warm Gold & Ivory" design system. No external CSS frameworks were used, ensuring a lightweight and completely tailored experience.
- **Vanilla JavaScript (ES6):** Handles all state management, dynamic DOM rendering, and booking logic.
- **Lucide Icons:** Clean, modern SVG iconography used throughout the interface.
